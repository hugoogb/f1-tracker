# Database backups

`latest.sql.gz` is a data-only dump of the F1 Tracker database (`pg_dump
--data-only --no-owner --no-privileges --exclude-table=alembic_version`),
regenerated by `../../scripts/db-backup.sh`. Restore it with
`../../scripts/db-restore.sh`, which migrates, loads the data and rebuilds the
materialized views — the views are not in the dump, and a database without them
serves empty career stats, records and champions.

**What it contains.** Everything the f1db release supplies: seasons, races,
drivers, constructors, circuits and layouts, results, qualifying, sprints,
standings and pit stops — 1950 to the current season.

**What it does not contain.** `lap_times` and qualifying sector times. Those
come from Fast-F1, which is throttled to roughly one session per 45 s, so they
are not practical to bundle. They accumulate on the VPS as
the weekly ingest workflow runs, and locally via
`cd pipeline && uv run python scripts/seed.py --laptimes --qualifying-sectors --year-range <years>`.
Until then the lap-times, tyre-strategy and position charts on race pages are
empty; everything else works.
